## 🧠 Overview

Affinity Designer is a professional vector graphics editor for creating illustrations, UI/UX designs, logos, icons, typography, and complex compositions. It combines precision vector tools with raster editing capabilities in a single unified workspace. It is developed by Serif. The product family is positioned as a vector graphics editor toolset for Windows workflows.

Affinity Designer works as a desktop application on Windows 10 and Windows 11 and is installed alongside a host application such as Affinity Photo.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| ✏️ Vector pen tools | Create smooth bezier curves and precise shapes with node editing, corner control, and automatic curve smoothing for professional illustration work. |
| 🎨 Non-destructive effects | Apply layer effects, shadows, glows, and adjustments that remain editable and can be saved as reusable styles without permanently altering artwork. |
| 🖼️ Artboard system | Work with multiple artboards of different sizes in one document for designing app screens, web pages, or multi-page print layouts simultaneously. |
| 🔤 Advanced typography | Full OpenType support with artistic text and text frames, kerning control, baseline adjustments, and text-on-path capabilities for editorial and branding work. |
| ⚙️ Symbols and components | Create reusable design elements that update globally across artboards, with support for nested symbols and overridable properties for UI design systems. |
| 🌈 Color management | End-to-end 16-bit per channel color with CMYK, RGB, LAB, and Pantone support, ICC profile handling for accurate print and screen color reproduction. |
| 📐 Constraints and grids | Isometric and standard grids with snapping, plus geometric and repeat transform tools for creating patterns, mandalas, and precise technical illustrations. |
| 🖌️ Pixel persona mode | Switch to raster editing with selection brushes, masking, filters, and retouching tools without leaving the document or converting vector objects permanently. |
| 📦 Asset export | Batch export artboards and slices to multiple formats and resolutions simultaneously with naming conventions for web and app development workflows. |
| 🔗 SVG and PDF support | Native SVG editing with clean code output, full PDF/X export for print, and import of Adobe Illustrator AI/EPS files with layer preservation. |
